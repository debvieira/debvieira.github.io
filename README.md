### Data Portfolio

Static editorial portfolio built for GitHub Pages.

Link: https://debvieira.github.io

### Publish

Upload all files and folders from this directory to the root of the `debvieira.github.io` repository. GitHub Pages will publish `index.html` automatically from the `main` branch.

## Edit

- Main page: `index.html`
- About page: `about.html`
- Project case studies: `projects/`
- Colors and layout: `assets/styles.css`
- Images: `assets/images/`

Professional cases intentionally generalize confidential details.
